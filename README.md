# Uriel Piu YT

Aplicativo Android para baixar vídeos do YouTube em MP4 e áudio em M4A ou WebM. O app permite abrir e copiar links diretos do Googlevideo e consultar o histórico de downloads.

## Instalação

Abra [Releases](https://github.com/irma1922rosa/uriel-piu-yt/releases) e baixe `Uriel_Piu_YT.apk` em **Assets**. Abra o APK no celular para instalar. Compatível com Android 5.1 ou superior.

## Código-fonte

O arquivo `Uriel_Piu_YT_codigo-fonte.zip`, disponível na mesma versão, contém o projeto Android e as instruções de compilação. O código é distribuído sob a licença GPL-3.0-or-later.
